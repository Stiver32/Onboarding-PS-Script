# Onboarding-PS-Script

PowerShell script for standardizing repetitive onboarding and user provisioning tasks.

## Purpose

Created to practice IT workflow automation and reduce repetitive manual steps during user setup.

## Features

- Collects new user information
- Generates standardized account details
- Validates required fields
- Produces repeatable onboarding output/checklists
- Supports consistent documentation for provisioning tasks

## Technologies Used

- PowerShell
- Windows administration concepts
- User provisioning workflow design

## Security Note

This is a public-safe version of an onboarding workflow. Company-specific names, domains, internal groups, and sensitive details have been removed.

## What I Learned

- PowerShell scripting fundamentals
- Input validation
- Automating repetitive IT tasks
- Creating more consistent onboarding workflows
